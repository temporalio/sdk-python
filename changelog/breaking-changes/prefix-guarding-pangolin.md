Workflow, activity, signal, query, and update names, Nexus service and operation names, and worker task queues can no longer start with the reserved `__temporal_` prefix, and queries can no longer be named `__stack_trace` or `__enhanced_stack_trace`. Using one now raises `ValueError` when the definition, handler, or worker is created.
Dynamic workflows, activities, and signal, query, and update handlers no longer receive names that start with `__temporal_`, and queries with reserved names, including the built-in `__stack_trace` and `__temporal_workflow_metadata`, no longer pass through worker interceptors.
Workflows already running that relied on a dynamic handler receiving a `__temporal_` name may fail their workflow tasks or hit nondeterminism errors on replay after upgrading.
